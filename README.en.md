# Free Douyin Live Monitor

Poll publicly visible Douyin live rooms and record start, end, title, and visible activity signals as timestamped snapshots. No third-party API key is required and it never posts or interacts automatically.

Requires [Easy WebBridge](https://github.com/xxjrq/easy-webbridge), with a [Gitee mirror](https://gitee.com/xxjrq/easy-webbridge) available.
